# 8pu 简谱平台调研报告

> 调研日期：2026-09-24  
> 调研对象：8pu（[8pu.cn](https://8pu.cn/)）  
> 调研目标：为 Score Trans 设计高度可自定义的简谱渲染界面提供产品和功能依据。  
> 资料范围：官网、官方帮助文档、Apple App Store 页面、官网公开截图。未登录 8pu，未进行需要账号的编辑器实测。

## 1. 结论摘要

8pu 是一个面向中文数字简谱的在线制谱平台，核心产品不是单一的“简谱转图片”工具，而是把谱型、输入、编辑、排版、播放、分享和跨设备同步放在同一个编辑器中。官网公开确认的谱型包括标准简谱、功能简谱和和弦谱；官方 App Store 页面确认了多声部、MIDI 播放、声部独立音量、拍号/调号/速度、转调、变速、装饰音、指法、连音线、延音线、三连音和 PDF/PNG 导出。

对 Score Trans 最有价值的设计不是某一个符号，而是把渲染控制拆成用户可以保存和复用的参数：页边距、行间距、音符和弦文字大小、颜色、小节编号、歌词输入方式、首行缩进，以及音名/级数和弦显示等。Score Trans 当前已经具备简谱领域模型、SVG/A4 渲染、PDF/PNG/文本/MIDI 输出和前端设置持久化基础，下一步应补齐“渲染主题/预设”这一层，把内容数据和视觉样式分离。

官方帮助中心已经确认 8pu 支持 8pux、MusicXML 和 MIDI 的导入/导出；但没有公开 8pux 的文件结构，也没有说明与 Score Trans 的直接兼容性。ABC、MuseScore 等其他互换格式仍未在官方资料中确认。

## 2. 产品识别与资料可信度

### 2.1 确认的产品

8pu（小写）是成都正在科技有限公司推出的简谱制谱平台。官网将其定位为“专业的简谱和功能谱制作平台”，并列出 Web、Windows、macOS、iOS、Android。官网同时说明部分客户端仍在测试或尚未发布，因此目前能够独立核验的原生客户端以 iPhone/iPad App Store 页面为主。

搜索中出现的“8PUS”是另一个历史项目，含义是“simple eight voice MIDI controlled audio synthesizer”，属于八声部音频合成器，不是 8pu 简谱软件，本报告不混用两者的功能。

### 2.2 证据等级

| 等级 | 资料 | 用途 |
|---|---|---|
| A | 8pu 官网与官方帮助中心 | 产品定位、公开功能清单、简谱语义、和弦输入规则 |
| A | Apple App Store 的 8pu 页面 | 移动端功能、版本、平台、更新项、开发者信息 |
| B | 官网公开截图和静态资源 | 编辑器、阅读模式、导出/分享界面形态 |
| C | 搜索结果、第三方页面 | 仅用于发现线索；不单独支撑关键功能结论 |

### 2.3 当前可核验版本和平台

- 官方 App Store 页面显示版本 `1.0.7`，要求 iOS/iPadOS 15.4 或更高版本。
- App Store 说明 iPhone/iPad 横屏优化、多点触控、云端同步、自动保存。
- 官网宣称 Web、Windows、macOS、iOS、Android 可用，但没有在本次公开资料核验中取得稳定的 Windows/macOS 安装包版本、Android 官方商店页面或公开源代码仓库。
- 登录页支持账号、短信和微信登录，并允许短信或扫码直接登录；本次没有使用账号进入编辑器。

## 3. 功能全量清单

### 3.1 谱型

| 谱型 | 产品定位 | 对渲染的影响 |
|---|---|---|
| 标准简谱 | 单行或多行记录旋律、和声、伴奏等独立声部，适合独唱、合唱、钢琴简谱和民乐合奏 | 需要多声部垂直对齐、声部间距和跨行布局 |
| 功能简谱 | 以主旋律、歌词和和弦功能为中心，接近台湾谱风格 | 需要每拍和弦位、歌词对齐、和弦/旋律层级和转调标记 |
| 和弦谱 | 以和弦、节奏型和演奏提示为中心，适合弹唱、排练和即兴 | 需要和弦占位、转位/斜杠低音、节奏型、反拍拆分 |

### 3.2 音符与基本记谱

官方简谱知识页确认或解释了以下语义：

- 数字 `1–7` 表示相对音级，实际音高由调号确定。
- 数字上方/下方的小圆点表示升高/降低一个或多个八度。
- `0` 表示休止符。
- 右侧延时线延长时值，下方横线缩短时值。
- 增时线以四分音符为基准增加时值。
- 支持附点音符。
- 支持升号、降号、重升、重降和还原记号。
- 支持普通小节线、双小节线和结束小节线。
- 帮助页列出段落反复、D.C、D.S、反复跳跃和不同结尾等反复概念。

App Store 进一步明确了装饰音、指法标记、连音线、延音线和三连音等专业符号。官网还列出多连音、弱起、扩展声部、散板和民乐记号。

### 3.3 输入方式

官网确认五种输入路径：

1. 外接 MIDI 键盘。
2. 电脑键盘映射。
3. 虚拟钢琴键盘。
4. 触控屏多点触控。
5. 按住 `Shift` 输入多音符。

这说明 8pu 的编辑器把“输入设备”与“谱面模型”分开处理；对 Score Trans 来说，未来可将文本编辑、鼠标点选、MIDI/钢琴输入都归一到同一事件编辑命令，而不是为每种输入方式复制一套渲染逻辑。

### 3.4 歌词、和弦和文本

- 歌词输入与歌词显示。
- 和弦输入与和弦类型切换。
- 文本标注。
- 转调。
- 和弦谱和功能简谱中的和弦位。
- 民乐符号和民乐音色播放。

官方和弦文档给出了较完整的和弦编辑操作：

- 支持音名和弦与级数和弦，并可在设置或看谱时切换。
- 和弦谱每拍提供和弦占位，可用数字键 `1–7` 快速切换级数或音级。
- 和弦工具栏会根据当前谱子中出现频率较高的和弦提供快捷项。
- `C` 打开和弦面板，`B` 设置转位/斜杠低音，`R` 设置节奏型，退格删除。
- 和弦位支持延音与休止符，可用减号和数字 `0` 输入。
- 和弦后的加号可拆分当前拍，以输入反拍和弦。
- 和弦节奏型可以独立添加、替换或删除。
- 和弦谱的转调信息记录在和弦上。

### 3.5 播放和看谱

- MIDI 播放。
- 内置多种乐器音色。
- 制作过程中实时试听。
- 多声部编辑和声部独立音量。
- 音名/级数显示切换。
- 一键移调看谱。
- 全屏查看。
- 双页查看。

这些功能要求渲染状态和播放状态共享稳定的时间轴、声部和移调模型。Score Trans 当前已有 MIDI 导出和播放器相关逻辑，后续应确保速度变化、声部静音/音量和渲染显示使用同一份结构化数据。

### 3.6 文件、同步和分享

- 在线链接分享。
- 源文件导出。
- WAV 音频导出。
- PDF 导出。
- PNG 图片导出。
- 一键打印。
- 自动保存。
- Web、iOS、Android 间云端同步。
- App Store 更新中新增文件列表侧边栏、回收站和本地字体支持。

官网称更多导出格式“即将支持”。公开资料没有给出源文件扩展名、文件结构或公开解析器。

### 3.7 账户与商业模式

- 基础版永久免费，不限谱子数量。
- PRO 会员解锁更多个性化样式或高级功能。
- App Store 标注内购项目。
- 登录方式包括账号、短信和微信。

本报告不把 PRO 的具体限制写成确定功能矩阵，因为官网没有公开逐项权限表。

## 4. 渲染与版式自定义矩阵

官网明确宣传的样式控制如下：

| 控制项 | 8pu 公开证据 | 对 Score Trans 的建议 |
|---|---|---|
| 页边距 | 可管理页边距 | 将纸张、方向和四边距放入 `RenderTheme`，参与分页测量 |
| 行间距 | 可管理行间距 | 区分声部间距、系统间距和段落间距，避免一个全局值覆盖所有情况 |
| 音符文字大小 | 可设置 | 使用独立音符字号，并让八度点、时值线和变音记号按字号缩放 |
| 和弦文字大小 | 可设置 | 与音符字号分离；支持和弦上方、同拍和弦位的不同间距 |
| 音符颜色 | 可设置 | 支持默认色、选中色、来源高亮色和打印色彩策略 |
| 和弦颜色 | 可设置 | 和弦、节奏型、低音/转位可有独立语义色，同时提供黑白打印模式 |
| 小节编号 | 可设置 | 支持显示/隐藏、起始编号、编号位置和重复小节策略 |
| 歌词输入方式 | 可选择 | 将歌词分词、音节绑定和显示换行策略建模为可配置选项 |
| 首行缩进 | 可设置 | 应参与标题、调号、第一小节和首行歌词的联合排版 |
| 音名/级数显示 | 支持切换 | 作为阅读视图和导出视图的显式显示模式，而不是修改源数据 |
| 和弦名/级数和弦 | 支持切换 | 和弦模型保留绝对和弦与级数语义，显示层负责转换 |
| 页面查看 | 全屏、双页 | 在现有 SVG 预览之上增加阅读模式布局，不改变导出几何 |
| 字体 | App Store 更新确认支持本地字体 | 增加字体选择、字体回退、字体嵌入/转路径和授权提示 |

### 4.1 建议的主题模型

建议在现有渲染请求旁边增加可持久化的主题对象，至少包含：

```text
RenderTheme
  paper: size, orientation, margins, background
  typography: note_font, note_size, chord_font, chord_size,
              lyric_font, lyric_size, annotation_font, annotation_size
  colors: note, chord, lyric, annotation, selection, source_highlight
  spacing: system_gap, staff_gap, voice_gap, lyric_gap, chord_gap,
           measure_gap, first_line_indent
  visibility: measure_numbers, title, tempo, key, fingering, dynamics
  notation: note_name_or_degree, chord_name_or_degree, octave_dot_style
  pagination: max_systems_per_page, keep_title_with_first_system,
              keep_lyric_line_with_notes
```

实现时应保留默认主题，并让每次渲染请求携带主题快照或 `theme_id + revision`，确保历史记录可以复现旧版输出。

### 4.2 不能直接照搬的地方

- 8pu 是交互式编辑器；Score Trans 目前以 OMR、MusicXML、简谱文本和 SVG 渲染为主，输入编辑体验不同。
- 8pu 的“源文件”格式未公开，不能作为 Score Trans 的互换目标。
- 8pu 的 PRO 样式权限没有公开细则，不能直接复制其收费边界。
- 官网截图能证明 UI 形态，不能证明截图中每个控件的完整行为或边界条件。

## 5. 与 Score Trans 当前能力的对照

Score Trans 当前已具备：

- `JianpuScore`、小节、事件、音高、歌词、和弦/文本块等领域模型。
- MusicXML ↔ 简谱转换。
- 简谱 SVG、批量 A4、PDF、PNG 和文本导出。
- MIDI 导出与播放相关前端能力。
- 渲染页、历史记录、渲染布局键和设置持久化。
- 来源 ID、SVG 高亮和编辑后重新渲染链路。

与 8pu 的主要差距集中在“用户可控的视觉系统”：

1. 样式值目前分散在渲染器、前端设置和页面 CSS 中，缺少统一的主题 DTO。
2. 字体、颜色、字号和间距还没有作为可版本化的渲染预设保存。
3. 和弦谱/功能简谱的和弦位、反拍拆分和节奏型布局需要更明确的领域数据结构。
4. 多声部的显示/隐藏、声部独立音量和声部间排版需要共享同一套声部标识。
5. 本地字体选择需要字体发现、回退、字体测量和导出一致性处理。
6. 页面预览、单页导出、双页阅读和打印需要区分视图布局与输出布局。

## 6. 面向 Score Trans 的实施路线

### 阶段一：主题和预设

- 新增 `RenderTheme` DTO 与默认主题。
- 将页边距、行间距、字号、颜色、首行缩进、小节编号放入主题。
- 设置页提供实时预览和恢复默认值。
- 历史渲染记录保存主题快照或稳定版本号。

### 阶段二：排版测量

- 把 SVG 绘制前的测量结果和主题参数绑定。
- 重新计算音符、和弦、歌词、文本块、八度点、时值线、连音线和分页位置。
- 为标题/调号/速度/第一行内容增加“不可拆分”约束。
- 增加黑白打印主题和高对比度主题。

### 阶段三：内容层样式

- 音符、和弦、歌词、标注、指法、力度、民乐记号分别支持字号/颜色/可见性。
- 音名/级数、和弦名/级数作为显示模式切换。
- 统一来源高亮、选中态和导出态颜色规则。

### 阶段四：功能谱和多声部

- 扩展和弦模型支持级数、音名、转位低音、节奏型、延音/休止和反拍拆分。
- 声部支持独立显示、音量和排序。
- 对标准简谱、功能简谱和和弦谱提供不同的布局策略，而不是仅切换少量开关。

### 阶段五：字体与交付

- 支持系统字体和用户字体目录。
- 导出前检查字体可用性，并决定嵌入字体、转路径或使用稳定回退字体。
- 对 PDF、PNG、SVG、打印和屏幕预览建立一致性快照测试。
- 保存可导入/导出的 Score Trans 渲染预设；不要依赖未公开的 8pu 源文件格式。

## 7. 建议的验收用例

1. 同一份简谱切换 10 组主题后，音符、歌词、和弦和分页均按预期变化。
2. 修改主题后历史记录仍能按旧主题复现原 SVG/PDF。
3. 音符字号变化不会造成八度点、变音记号、时值线和连音线错位。
4. 长歌词、中文歌词、和弦密集段落在不同页边距下不重叠。
5. 多声部隐藏/显示不改变未隐藏声部的音高和时值语义。
6. 音名/级数和弦切换只改变显示，不破坏来源 ID、转调和播放。
7. 屏幕预览、PDF、PNG 和打印使用同一主题时，关键几何位置一致。
8. 本地字体缺失时有明确回退，并且不会生成空白或截断的字形。
9. 黑白打印主题不会丢失变音、力度、指法和来源高亮之外的必要语义。
10. 主题 JSON 可校验、可迁移，并拒绝非法字号、负间距和不可用颜色值。

## 11. 官方帮助中心深入调研：8pu 的谱面自定义边界

本节以官方帮助中心页面为主，区分“改变谱面内容”与“改变谱面呈现”。8pu 的优势在于这两类设置同时存在：用户可以先改变小节、声部、歌词和标注的结构，再用全局样式或单个对象样式控制最终外观。

### 11.1 全局谱面样式

官方页面《谱面样式：字体、背景与水印》确认了以下可操作项：

| 样式域 | 官方支持的控制 | 影响对象 |
|---|---|---|
| 字体 | 分别设置字体 | 标题、音符、歌词、和弦、谱头信息、标注 |
| 字号 | 分别设置字号 | 上述每一类文字 |
| 颜色 | 分别设置颜色 | 上述每一类文字、小节线、重复标记 |
| 和弦/标注背景 | 单独设置背景颜色 | 和弦框、标注框 |
| 小节线/重复标记 | 分别设置样式 | 小节线、反复记号 |
| 纸张比例 | 选择不同纸张长宽比 | 整页几何与分页 |
| 背景 | 纯色或图片，图片可调透明度 | 整页背景 |
| 水印 | 文字或图片，支持平铺、透明度、旋转角度 | 整页水印 |
| 页码 | 开关、位置、字体、颜色 | 分页页脚或指定页码区域 |
| 页边距 | 自定义页面边距 | 内容区域与分页测量 |

这比官网首页的“音符和弦文字大小或颜色”更具体：8pu 不是只有一个全局字体大小，而是按谱面对象类别拆分配置；水印、页码、背景和纸张比例也属于导出页面的一等配置。

### 11.2 歌词的布局自定义

官方《歌词编辑、对齐与排版》把歌词排版分成谱型和输入方式：

- 标准简谱默认按音符一一对应；空格用于移动到下一个音符。
- 简谱支持在同一小节添加多行歌词；多声部时先选中对应声部再添加。
- 功能简谱可为拓展旋律单独添加歌词。
- 功能谱默认按小节输入，歌词不会自动与节拍对应，用户用空格微调位置。
- 和弦谱默认按小节输入，也可切换为整行输入。
- 当歌词与音符重叠时，官方给出三种处理路径：减小歌词字号、减少一行内小节数量、切换为整行自由输入。
- 歌词行前可以添加标注，标注跟随该歌词行或段落显示。

这说明 8pu 的“歌词输入方式”并非纯编辑偏好，而是直接参与布局算法：音符对齐、按小节对齐和整行自由定位需要不同的测量和换行规则。

### 11.3 标注的全局样式和单对象样式

官方《标注：拖动放置与单独样式》确认两级样式：

- 全局样式：设置中为所有标注提供基础字体、颜色和背景样式。
- 单独样式：选中某个标注后，可单独修改字体、文字颜色和背景颜色。
- 标注可以切换到拖动状态，放置在用户需要的位置。
- 歌词行、歌词段落和和弦谱小节歌词前都可以放置标注。

对 Score Trans 而言，这意味着主题系统必须支持“类别默认值 + 对象局部覆盖”，不能只提供一个全局 annotation 样式。

### 11.4 多声部的显示与编排自定义

官方《多声部管理与声部设置》确认：

- 声部可以排序、重命名、选择乐器音色。
- 可以控制是否在谱面显示声部名称。
- 支持直连谱号、花连谱号和辅助连谱线，并可通过分组/子分组组织声部。
- 每个声部可以在局部片段显示或隐藏。
- 拓展旋律可以形成主从声部记法，并按小节继续拓展或删除。
- 自由旋律可以添加后自由拖动到任意位置。

这些功能同时改变语义结构和视觉结构：声部名称、括号/连谱号、分组、局部显隐和自由旋律都需要进入布局树，而不能只作为 SVG 绘制时的装饰。

### 11.5 小节、行和节拍布局

官方《小节操作与编辑技巧》确认以下排版控制：

- 小节线类型可单独设置，支持重复开始和结束同时标记。
- 支持变拍、变速、反复记号和重复房子。
- 可以插入/删除小节、把小节移动到下一行或上一行。
- “重置行”根据设置中的“行小节数”自动重新排列。
- 标准简谱默认自动计算小节宽度，也可以选择行内等分。
- 和弦谱默认行内等分。
- 和弦谱可以设置跳过小节，默认隐藏这些小节以形成段落区隔。

官方更新记录还确认：

- `v0.3.4`：简谱支持小节行内等分布局；最后一行小节数不足时不自动铺满整行。
- `v0.1.0`：增加每行小节数配置。
- `v0.3.2`：支持每行显示声部名。
- `v0.3.7`：支持散拍子和小节线/反复记号自定义样式。

因此，8pu 的行布局至少有三种彼此独立的控制：每行小节数量、自动宽度/行内等分、最后一行是否拉伸填满。Score Trans 当前的 `content_scale/system_gap/short_note_gap/beat_gap` 更接近“几何缩放”，还没有这类行级布局策略。

### 11.6 谱型级别的版式选择

官方《乐谱类型》指出，和弦谱有两种版式，功能相同但视觉风格不同；创建曲谱时选择，创建后不能更改。官方历史更新显示早期版本已有“格子版式功能谱”，并特别调整了和弦显示字号。

这是一种重要的产品设计：谱型选择和版式选择是创建时的结构性决策，不应被实现成渲染后随意切换的 CSS 皮肤。Score Trans 如果增加功能简谱/和弦谱，应在文档模型中保存 `score_type` 与 `layout_variant`，并让渲染器按谱型选择布局策略。

### 11.7 版本更新暴露的新增自定义项

官方更新记录（截至 2026-09-08 的 `v1.0.8`）是目前最具体的能力时间线：

- 转调显示可以切换音名/级数。
- “记谱 > 音符显示”新增附点显示位置调整。
- “小节内升降号显示”可以设置。
- 支持设置默认模板样式。
- 最多添加 20 行歌词。
- `v1.0.5` 新增双附点、三附点、多小节休止、声部局部显隐和自由旋律。
- `v1.0.4` 支持标注拖动与单独样式。
- `v1.0.2` 支持本地字体、样式模板、连音线/力度符号拖动和力度符号移动到音符上方。
- `v0.3.2` 支持整行自由歌词、更多乐器记号、`cresc.`/`dim.`、每行显示声部名。
- `v0.2.2` 首次加入字体、大小、颜色配置。

这条时间线表明 8pu 的“高度自定义”是逐步从全局样式扩展到对象样式、局部位置、显示规则和模板持久化，而不是一次性提供一个主题颜色选择器。

## 12. Score Trans 当前自定义能力盘点

以下结论来自当前代码，而不是根据旧文档推测。

### 12.1 已有并且已经进入用户设置的控制

当前 [AppearanceSettingsPanel.vue](../desktop/src/renderer/src/components/settings/AppearanceSettingsPanel.vue) 暴露：

- 内容缩放 `65%–100%`。
- 系统/行间距 `20%–180%`。
- 短音符间距 `20%–180%`。
- 节拍边界间距 `0%–200%`。
- 是否按拍点断开节奏线。
- 应用界面浅色/深色/跟随系统。
- 识别层和 OCR 层显示开关。

当前 [ConversionSettingsPanel.vue](../desktop/src/renderer/src/components/settings/ConversionSettingsPanel.vue) 暴露：

- 目标调、变音偏好。
- 小节编号：全部、每行开头、不显示。
- 多声部是否展平。
- 自动移调、语法高亮、时值检查。

这些设置通过 `SettingsResponse`、`SettingsUpdateRequest` 和 `A4LayoutRequest` 保存，并参与渲染请求。它们属于“全局几何和转换规则”，不是完整的谱面样式系统。

### 12.2 后端已有但没有完整用户入口的参数

当前 [RenderOptions](../backend/score_trans/services/render/options.py) 和 [PublicationStyle](../backend/score_trans/services/render/engraving/style.py) 已包含：

- 字体族。
- 音符、变音、歌词、标注和小节编号的字号。
- 标题、谱头信息、声部名称、页面编号的字号常量。
- 页面宽高和左右/上下边距。
- 最小小节宽度、事件间距、节拍边界间距、声部间距、歌词留白、标注留白。
- 标题显示、页面编号显示、小节编号显示。
- 连音线、延音线、连梁、三连音、力度、八度点等几何间距。

但公开渲染请求的 [A4LayoutRequest](../backend/score_trans/models/render/layout.py) 目前只暴露内容缩放、系统间距、短音间距、节拍间距和断梁开关；`RenderJianpuSvgRequest` 等请求也没有字体、颜色、背景、水印、页码样式或按对象类别的覆盖字段。因此大量 `PublicationStyle` 数值是工程常量，不是用户可以自定义的产品能力。

### 12.3 当前明确欠缺的自定义能力

| 8pu 官方能力 | Score Trans 当前状态 | 缺口级别 |
|---|---|---|
| 标题/音符/歌词/和弦/谱头/标注分别设置字体 | 仅有内部默认字体族和少数字号常量 | P0 |
| 各类文字分别设置颜色 | 没有公开渲染颜色主题字段 | P0 |
| 和弦、标注背景颜色 | 没有对应模型或 UI | P0 |
| 小节线/重复标记样式 | 领域有部分记号，但没有统一样式设置 | P1 |
| 纸张长宽比 | A4 渲染是固定主路径，公开请求没有纸张比例字段 | P0 |
| 纯色/图片背景 | 未发现渲染请求、主题或导出配置 | P0 |
| 文字/图片水印、透明度、旋转、平铺间隙 | 未发现实现 | P1 |
| 页码开关、位置、字体、颜色 | 有页面编号显示逻辑，但无完整样式配置 | P1 |
| 页面四边距独立调整 | `RenderOptions.margin` 只提供单一值，A4 公开请求未暴露 | P0 |
| 默认模板/样式预设 | 没有主题实体、模板列表或主题版本 | P0 |
| 标注拖动和单对象样式 | 有文本块/附件数据，但没有用户级样式覆盖和拖动布局 UI | P1 |
| 歌词按音符、按小节、整行自由输入 | 当前简谱文本解析/渲染没有公开布局模式选择 | P0 |
| 每行小节数、自动宽度/行内等分、末行填充策略 | 当前只有间距比例，没有行级布局策略 | P0 |
| 和弦谱两种固定版式 | 当前没有功能简谱/和弦谱的独立布局变体 | P1 |
| 声部名称、声部排序、括号/分组、局部显隐 | 有多声部解析和部分渲染，但缺少完整用户控制面板 | P1 |
| 音名/级数、和弦名/级数显示 | 有调号/目标调逻辑，缺少独立显示模式字段 | P1 |
| 附点位置、小节内升降号显示 | 当前没有公开显示规则字段 | P1 |
| 本地字体与导出一致性 | 默认字体资源存在，缺少用户字体选择/嵌入/回退流程 | P1 |
| 8pux 样式随项目保存 | 当前历史记录保存渲染布局键，但不是完整主题快照 | P0 |

### 12.4 当前产品层面的根本差异

Score Trans 现在是“转换设置 + 渲染几何参数”，8pu 已经是“谱面对象样式系统 + 行/页布局系统 + 项目级模板”。因此直接继续增加几个 slider 不能达到用户所说的高度自定义；需要先建立稳定的渲染主题和布局策略接口。

## 13. 对 Score Trans 的重新排序建议

### P0：先建立可复现的主题与布局基础

1. 新增 `RenderTheme`，至少包含纸张比例、四边距、背景、字体、字号、颜色、页码、水印、歌词模式和行布局模式。
2. 将主题作为渲染请求的一部分，并把完整主题快照或版本写入历史渲染状态；不能只保存当前 5 个百分比参数。
3. 为音符、歌词、和弦、标注、谱头、标题、声部名、小节编号分别提供样式对象。
4. 将 `PublicationStyle` 中的工程常量分成三类：用户可配置、主题派生、严格内部安全边界，避免把所有浮点常量直接暴露给用户。
5. 增加每行小节数、自动宽度/等分、末行填充、分页保持规则等布局策略。

### P1：补齐 8pu 的对象级和谱型级能力

1. 支持标注的全局默认样式与单个标注覆盖。
2. 支持和弦框背景/边框、节奏型和转位的独立布局。
3. 支持声部名称显示、声部排序、局部显隐和分组括号。
4. 支持音名/级数和弦显示、附点位置、小节内升降号显示等显示规则。
5. 为标准简谱、功能简谱、和弦谱建立独立布局策略和创建时固定的版式变体。

### P2：交付质量和生态能力

1. 支持纯色/图片背景、文字/图片水印、页码位置与旋转/透明度。
2. 支持用户字体、字体回退和 PDF/PNG/SVG 字形一致性检查。
3. 设计可导入导出的 Score Trans 主题文件，内容参考 8pux 的“音符、和弦、歌词、样式设置完整保存”思路，但使用公开、版本化的 JSON schema。
4. 增加主题快照测试：同一文本在不同主题下生成不同 SVG，历史主题升级后仍可复现旧输出。
