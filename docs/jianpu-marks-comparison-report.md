**最突出的系统性差异（按严重程度）：**

1. **指法序号用字错误（❌，14–17）**：参考（图1）明确"指序"使用汉字 **一、二、三、四**，当前渲染为阿拉伯数字 `1 2 3 4`，且与音符数字几乎重叠。
2. **连线滑音/有时值滑音符号体系不同（❌，10、37、44、45）**：参考（图1"连线滑音"、图4"有时值上/下滑音"）为**连接两音、带箭头的弧线**（弧线在两音上方或音符右上角的 ↗/↘ 弧箭头）；当前渲染为**内联 "Z" 字形字符**夹在两音之间，形态完全不同。
3. **扫摇（❌，49）**：参考（图3）"扫摇"为连续 "⌐" 折角符号组；当前渲染为"波浪线+斜杠"组合，属于不同符号体系。
4. **扫弦（❌，50；⚠️，39）**：参考（图3）扫弦为**竖直向下箭头 + 双斜杠**（谱例中箭头纵贯多音）；当前渲染为**斜向 ↗ 箭头**，方向与形态均不同。
5. **顿弓/断音（❌，03）**：参考（图1）顿弓(跳弓)为**实心倒三角 ▼**，置于音符正上方；当前渲染为西式小圆点 `.`，且位于音符右上侧。

## 四、跨项通用问题（不针对单个符号）

1. **标记尺寸普遍偏小**：绝大多数符号高度不足音符数字的一半。参考书籍中符号与音符尺寸相近（如 ▼、九、⌐、↗），小符号是当前渲染与"正规出品"观感差距最大的共性因素。
2. **间距不足/相触**：09/36/43 斜杠贴住音符；14–17 指法数字与音符重叠；01 重音贴近音符顶部。参考谱例中标记与音符均有明显留白。
3. **箭头表达弱**：参考中滑音/刮奏类均以"带箭头的弧线/长箭头"呈现，当前多为短钩、省略箭头，表意依赖输入码提示。
4. **逆回音与回音不可区分**（05 vs 06）：两者应呈上下翻转关系。
5. **截图/检查工具侧问题（非渲染问题）**：35/42/49/51/52/61 等图左上角标题文字与 `(^…)` 徽标被左侧色条裁切；51/52 标签 "(^…" 显示不全。
6. **参考覆盖缺口（建议补充用例的方向，仅记录）**：连弓 ⌒、连顿弓、tr 度数标注、游摇 >~~~<、逗弓/句弓/分弓（∨ 系变体）、点音 ↓、回滑音 ∞、按音 (3)⑥、柱音 ⊕/⊙ 等在参考图中存在但用例未覆盖。

## 五、结论摘要

- **完全一致（21 项）**：弓法（拉弓/推弓）、泛音、拨弦、大小滑音斜线、上颤音、空弦/内外弦、摇指斜杠、双托/双抹、板前花/正板花、刮奏箭头、揉弦波浪等核心符号已达到参考出品形态。
- **需要重点修正（11 项 ❌）**：指序汉字化（一二三四）、连线滑音改为带箭头弧线、顿弓改 ▼、扫摇改 "⌐" 符号组、扫弦改竖直向下箭头。
- **建议打磨（20 项 ⚠️）**：统一放大符号字号、增加与音符的垂直间距、补全箭头/波浪延长线、区分回音与逆回音。
- **无参考对照（9 项 ➖）**：西式记号与阮类/整小节简写，建议另行引入对应乐器的正规符号表核对。
