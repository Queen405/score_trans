# 简谱文本语法（Jianpu Text Syntax）

本项目使用纯文本描述简谱，经解析后渲染为 SVG 谱面或转写为 MusicXML。语法设计目标是：**看到什么符号，就输入什么符号**，让乐谱编辑像打字一样自然。

---

## 1. 谱面基本信息

写在正文前的元数据行，控制整首曲子的调号、拍号、标题和速度。

| 指令 | 说明 | 示例 |
|------|------|------|
| `1=` | **调号**。用大调主音表示，如 `C`、`G`、`F`、`D`、`Bb`。 | `1=C` |
| `4/4` | **拍号**。分子为每小节拍数，分母为以几分音符为一拍。 | `3/4`、`6/8` |
| `title=` | **标题**。可包含空格，不需要引号。 | `title=小星星` |
| `tempo=` | **速度**。20–300 的整数 BPM；省略时按 120 播放。 | `tempo=120` |
| `instrument=` | **乐器模式**（可选）。决定可用的演奏技巧标记：`general`（普通）、`erhu`（二胡）、`ruan`（阮）、`guzheng`（古筝）。`zhongruan`（中阮）作为 `ruan` 的别名同样可用。 | `instrument=erhu` |

**示例 — 一首完整曲头：**

```text
title=小星星变奏曲
1=C
4/4
tempo=100
instrument=erhu
```

> **注意**：调号 `1=`、拍号 `4/4` 与速度 `tempo=` 都可写在目标小节的第一个音符之前，对该小节及后续小节生效。中途变速的规范写法是独占一行；行内 `tempo=80 1 2 3 4 |` 仅作为兼容输入，规范化后会改为独占行。速度不能写在小节音符之后。旧写法 `key=C`、`time=4/4` 已废弃，请改用 `1=C`、`4/4`。

**示例 — 从第二小节开始变为 80 BPM：**

```text
tempo=120
1=C
4/4
1 2 3 4 |
tempo=80
5 6 7 1' |
```

## 2. 音符（音级与八度）

用数字 `1`–`7` 表示七个音级，对应 do、re、mi、fa、sol、la、si。

| 符号 | 说明 | 渲染效果 |
|------|------|----------|
| `1` `2` `3` `4` `5` `6` `7` | 基本音级（中音区） | 数字音符 |
| `1'` `2'` | 单引号 `'` 表示**高八度**，可叠加 | 数字 + 上圆点 |
| `1,` `2,` | 逗号 `,` 表示**低八度**，可叠加 | 数字 + 下圆点 |
| `1''` `1,,` | 双引号/双逗号表示**再高/低一个八度** | 两个上/下圆点 |

**示例：**

```text
1 2 3 | 1' 2' 3' | 1, 2, 3, |
```

---

## 3. 临时升降号

写在音级前面或后面，表示临时变音。

| 符号 | 说明 | 示例 |
|------|------|------|
| `#` | 升半音 | `#4`（fa → #fa） |
| `b` | 降半音 | `b7`（si → ♭si） |
| `x` | 重升（全音） | `x4`（fa → xfa） |
| `bb` | 重降（全音） | `bb7`（si → 𝄫si） |
| `n` 或 `♮` | 还原 | `n4`（还原4） |
| `qs` | 四分之一升（半个半音） | `qs1` |
| `qf` | 四分之一降（半个半音） | `qf2` |
| `tqs` | 四分之三升（一个半音半） | `tqs3` |
| `tqf` | 四分之三降（一个半音半） | `tqf4` |

> `#` / `b` 可前置或后置，效果相同：`#5` 与 `5#` 等价。还原号和微音程
> accidental 只能前置。`qs1` 会按最长前缀解析为四分之一升的四分音符，
> 不会被拆成时值前缀 `q` + `s1`。

> MusicXML 会无损保留微音程。SVG 当前使用 `qs` / `qf` / `tqs` / `tqf`
> 文本 glyph；MIDI 导出尚未分配 pitch bend 通道，遇到微音程会明确报错而不会取整。

## 4. 休止符

| 符号 | 说明 |
|------|------|
| `0` | 休止符，默认时值为一拍（四分休止） |
| `w0` | 全休止（4 拍） |
| `h0` | 二分休止（2 拍） |
| `q0` | 八分休止（½ 拍） |
| `s0` | 十六分休止（¼ 拍） |

> 休止符 `0` 与音符 `1`–`7` 的时值规则完全相同，可加任意时值前缀（`w/h/q/s/d`）、附点或延长线。

---

## 5. 时值控制

默认每个音符/休止符的时值等于 **一拍**（以四分音符为一拍时）。通过以下方式改变时值：

### 5.1 时值前缀（推荐新写法）

在音符前加字母前缀，直接指定音符类型：

| 前缀 | 含义 | 对应拍数（以 4/4 为例） | 示例 |
|------|------|------------------------|------|
| *(无)* | 四分音符 | 1 拍 | `1` `3` `5` |
| `q` | 八分音符（quaver） | ½ 拍 | `q1` `q3` `q5` |
| `s` | 十六分音符（semiquaver） | ¼ 拍 | `s1` `s2` |
| `d` | 三十二分音符（demisemiquaver） | ⅛ 拍 | `d1` |
| `dd` | 六十四分音符 | ¹⁄₁₆ 拍 | `dd1` |
| `ddd` | 一百二十八分音符 | ¹⁄₃₂ 拍 | `ddd1` |
| `dddd` / `ddddd` | 更短的二次幂时值 | ¹⁄₆₄ / ¹⁄₁₂₈ 拍 | `dddd1` `ddddd1` |
| `h` | 二分音符（half note） | 2 拍 | `h1` |
| `w` | 全音符（whole note） | 4 拍 | `w1` |

> 时值前缀按最长合法前缀读取；例如 `db7'` 表示 `d`（三十二分音符）加
> `b7'`（降 7、高八度），不是一个独立的 `db` 前缀。

**示例 — 一小节混合时值：**

```text
q1 q2 q3 q4 | s1 s1 s1 s1 q2 q3 |
```

### 5.2 附点

在音符后加 `.`，时值延长 **自身的一半**。

| 写法 | 说明 | 总拍数 |
|------|------|--------|
| `5.` | 附点四分音符 | 1 + ½ = 1.5 拍 |
| `h5.` | 附点二分音符 | 2 + 1 = 3 拍 |
| `q5.` | 附点八分音符 | ½ + ¼ = ¾ 拍 |

### 5.3 延音线（Tie）

用波浪号 `~` 将两个同音高的音符连成一体，**总时值为两者之和**，谱面显示为延音弧线。

| 写法 | 说明 |
|------|------|
| `5~` | 当前音为延音起点 |
| `~5` | 当前音为延音终点 |

**示例 — 一个跨小节的二分音符：**

```text
1 2 3 5~ | ~5 3 2 1 |
```

> 只有**同音高**的音符才能连延音线；不同音高请使用连音线 `()`。

### 5.4 连音组（Tuplet）

用 `$ ... $` 把一组音符括起来。省略显式比例时，所有音平均分配 1 拍；
显式比例写在组首，格式为 `实际数:常规数;`，此时每个音以四分音符为基准，
按 `常规数/实际数` 缩放。

| 写法 | 说明 |
|------|------|
| `$123$` | 三连音，3 个音共占 1 拍 |
| `$1234$` | 四连音，4 个音共占 1 拍 |
| `$1 2 3 4 5$` | 五连音，组内用空格分隔也可 |
| `$3:2;1 2 3$` | 显式 3:2 比例，3 个音共占 2 拍 |
| `$3:4;1 2 3$` | 显式 3:4 比例，3 个音共占 4 拍 |

> 省略显式比例时，连音组至少需要 2 个音。组内可以带升降号、八度标记和
> 演奏标记，但**不允许时值前缀**（`$q1 q2 q3$` 这类写法会报语法错误）。
> 组外禁止出现 `27`、`356` 这类连续多位数字——它们不是音高。

## 6. 小节与曲式结构

| 符号 | 说明 | 渲染效果 |
|------|------|----------|
| `|` | 小节线 | 竖线分隔 |
| `||` | 终止线（双竖线） | 细线 + 粗线 |
| `|:` | 反复起始 | 左粗右细 + 两个圆点 |
| `:|` | 反复结束 | 左细右粗 + 两个圆点 |
| `*N` | 反复次数，写在 `:|` 之前，表示该段重复 N 遍 | 小节号相应增加 |

**示例 — 带反复与重复次数的乐段：**

```text
|: 1 2 3 4 | 5 6 5 4 *2 :||
```

> 上例中 `*2` 表示 `5 6 5 4` 这一小节重复 2 遍。行首出现 `12:` `10.` 等小节编号会自动忽略，方便你从现有乐谱直接复制粘贴。注意 `1.`–`7.` 是附点音符（见 5.2），不会被当作小节编号；只有冒号结尾（`12:`）或数字大于 7（`10.`）才按编号剥离。

---

## 7. 和弦

用方括号 `[ ]` 把多个音级括起来，音级之间用 `+` 分隔。和弦音在谱面中**纵向排列**，最高音在上。

| 写法 | 说明 |
|------|------|
| `[1+3+5]` | C 大调和弦（do + mi + sol） |
| `[5+7+2']` | G 大调和弦 |
| `q[1+3+5]` | 八分音符和弦 |

**示例：**

```text
1 2 [1+3+5] | 6 [6+1'+3'] 5 [5+7+2'] |
```

---

## 8. 连音线（Slur）

用圆括号 `(` `)` 标记连音（圆滑奏）范围，谱面显示为弧线连接括号内的所有音符。

| 写法 | 说明 |
|------|------|
| `(5 6 7 1')` | 四个音一组连音 |
| `(q1 q2 q3 q4)` | 带时值的连音组 |

> 连音线可以跨小节，但不能嵌套。

连音线跨过连音组边界时，括号写在 `$...$` 外，例如
`($123$ 4)` 或 `(1 $234$)`；这样连音组内部始终保持括号配对。

## 9. 力度与演奏法标记

### 9.1 力度标记

在音符前写 `\` 加力度符号，作用于其后的第一个音符。

| 写法 | 含义 | 渲染效果 |
|------|------|----------|
| `\pppp` | 极弱（pianissississimo） | *pppp* |
| `\ppp` | 极弱（pianississimo） | *ppp* |
| `\pp` | 很弱（pianissimo） | *pp* |
| `\p` | 弱（piano） | *p* |
| `\mp` | 中弱（mezzo-piano） | *mp* |
| `\mf` | 中强（mezzo-forte） | *mf* |
| `\f` | 强（forte） | *f* |
| `\ff` | 很强（fortissimo） | *ff* |
| `\fff` | 极强（fortississimo） | *fff* |
| `\ffff` | 极强（fortissississimo） | *ffff* |
| `\fp` | 强后弱（fortepiano） | *fp* |
| `\sfz` | 突强（sforzando） | *sfz* |
| `\sfp` | 突强后弱（sforzando-piano） | *sfp* |
| `\sf` | 突强（sforzando） | *sf* |
| `\fz` | 强调（forzando） | *fz* |
| `\rfz` | 加强（rinforzando） | *rfz* |

**示例：**

```text
\p 1 2 3 4 | \f 5 6 5 4 |
```

### 9.2 演奏法标记

在音符前写 `^` 加标记，作用于其后的第一个音符。

| 写法 | 含义 | 渲染效果 |
|------|------|----------|
| `^.` | 断奏（staccato） | 实心倒三角 |
| `^>` | 重音（accent） | `>` 记号 |
| `^-` | 保持（tenuto） | 横线 |
| `^r` | 颤音（trill） | *tr* |
| `^f` | 延音记号（fermata） | fermata 形状 |
| `^l` | 轮指（tremolo），仅 `erhu`/`ruan`/`guzheng` 模式可用 | 三道斜线 |
| `^!` | 短断音（staccatissimo） | 短断音标记 |
| `^t` | 回音（turn） | 回音标记 |
| `^t'` | 逆回音（inverted turn） | 逆回音标记 |

**示例：**

```text
1 ^.2 ^>3 ^-4 | ^r5 4 3 2 |
^l 5 ^l 6 | ^l 7 1' |
```

### 9.3 小节级简写

如果一整小节的音符都要加同一种演奏法，可在小节开头用括号简写，作用于该小节内所有音符与和弦（休止符不继承）：

| 写法 | 含义 |
|------|------|
| `(^l)` | 整小节震音/轮指 |
| `(^.)` | 整小节跳音 |
| `(^>)` | 整小节重音 |
| `(^r)` | 整小节颤音 |
| `(^f)` | 整小节延音记号 |

```text
(^l) 1 2 3 4 | (^.) q1 q2 q3 q4 |
```

> 这只是简写，等价于逐音写 `^l`、`^.`。在二胡/阮/古筝等乐器模式下，整小节轮指/摇指/震音常用 `(^l)` 表示。详见应用内「语法参考 → 演奏技巧」。

## 10. 歌词

用 `L:` 开头的一行定义歌词，单词用空格分隔，每个单词自动与对应小节的音符对齐。

**示例：**

```text
1=C
4/4
1 1 5 5 | 6 6 h5 |
L: 一 闪 一 闪 亮 晶 晶
```

> 歌词与音符按顺序一一对应；休止符不分配歌词。若歌词数量少于音符，多余的音符不显示歌词；若歌词数量多于音符，多余的词会被忽略。

---

## 11. 注释

用 `//` 表示行内注释，从 `//` 开始到当前行末尾的内容会被解析时忽略。

```text
1=C
4/4
1 2 3 4 | 5 6 7 1' | // 这是一段行内注释
```

> 注意：`#` 是升号（如 `#4`），**不是**注释符。需要注释请一律使用 `//`。

---

## 12. 多分谱与分页

### 12.1 分谱标记

用 `// @part` 标记将多个声部写在同一段文本中。每个分谱以 `// @part 序号 name="名称"` 开头，序号从 1 开始连续递增：

```text
// @part 1 name="右手"
1=C
4/4
1 2 3 4 | 5 6 5 4 |

// @part 2 name="左手"
1=C
4/4
w1 w1 | w5 w5 |
```

> 第一个分谱标记之前不能包含简谱正文。名称中的引号需要转义为 `\"`。

### 12.2 分页标记

用 `// @page` 标记将多页输入合并为一段文本。格式为 `// @page 序号 start=起始小节号`，起始小节号填 `auto` 自动续接或具体数字：

```text
1=C
4/4
1 2 3 4 | 5 6 7 1' |
// @page 2 start=auto
2 3 4 5 | 6 7 1' 2' |
```

> 分页标记序号也必须从 1 开始连续递增。`start=auto` 表示自动续接上一页的小节号；填具体数字则从该小节号开始。可选的 `name="名称"` 用于标注输入文件名。

## 13. 完整示例

下面是一段完整的《小星星》简谱文本：

```text
title=小星星
1=C
4/4
tempo=100

1 1 5 5 | 6 6 h5 | 4 4 3 3 | 2 2 h1 |
L: 一 闪 一 闪 亮 晶 晶 满 天 都 是 小 星 星

5 5 4 4 | 3 3 h2 | 5 5 4 4 | 3 3 h2 |
L: 太 阳 慢 慢 向 西 沉 乌 鸦 回 家 一 群 群

1 1 5 5 | 6 6 h5 | 4 4 3 3 | 2 2 h1 |
L: 一 闪 一 闪 亮 晶 晶 满 天 都 是 小 星 星
```

**更复杂的示例 — 混合时值与装饰：**

```text
title=练习曲
1=G
4/4

\mf 1 2 3 4 | q5 q5 q3 q1 q5 q5 q3 q1 | h2. q3 q4 | w1 |
L: 春 眠 不 觉 晓 处 处 闻 啼 鸟 飞 飞 飞 去 去 去

\p (5 6 5 4) | 3 2 1 ~1 | 2 3 4 3 | h2 h0 |
L: 夜 来 风 雨 声 花 落 知 多 少 安 睡 吧
```

## 14. 语法速查表

| 符号 | 功能 |
|------|------|
| `1`–`7` | 音级 do–si |
| `0` | 休止符 |
| `'` `,` | 升高/降低八度 |
| `#` `b` `x` `bb` `n` | 升、降、重升、重降、还原 |
| `qs` `qf` `tqs` `tqf` | 微音程：四分之一升/降、四分之三升/降 |
| `q` `s` `d` `h` `w` | 八分、十六分、三十二分、二分、全音符 |
| `dd` `ddd` `dddd` `ddddd` | 六十四至一百二十八分音符 |
| `.` | 附点（写在音级后） |
| `-` | 延长线（每个延长一拍） |
| `~` | 延音线 |
| `( )` | 连音线（圆滑奏） |
| `$[实际数:常规数;]...$` | 连音组；比例可省略，省略时组内音符均分 1 拍 |
| `[a+b+c]` | 和弦 |
| `|` `||` `|:` `:|` `*N` | 小节线、终止线、反复起止、反复次数 |
| `\p` `\f` `\sfz` 等 | 力度 |
| `^.` `^>` `^-` `^r` `^f` `^l` | 演奏法（断奏、重音、保持、颤音、延音、轮指） |
| `(^l)` `(^.)` 等 | 小节级演奏法简写 |
| `L:` | 歌词行 |
| `//` | 行内注释（`#` 是升号，不是注释） |
| `1=` `4/4` `title=` `tempo=` `instrument=` | 调号、拍号、标题、速度、乐器模式 |
| `// @part N name="..."` | 分谱标记 |
| `// @page N start=auto|数字` | 分页标记 |

> **旧写法迁移提示**：本项目已弃用旧版 `key=`/`time=` 头部与 `/` 减时线。请改用 `1=C`、`4/4` 头部，并用 `q`、`s`、`d`、`h`、`w` 时值前缀代替 `/`（例如旧写法 `3/` 改为 `q3`，`6//` 改为 `s6`）。
