# 单个小节的出版级简谱布局调研

调研日期：2026-11-09。代码基线：`650ca1a6`，引擎 `publication-33`。本轮为研究、测量与问题复现，未修改产品排版算法或用户设置。命令使用 Bash，Python 使用项目 `.venv/Scripts/python.exe`。

**结论：小节内部的排版应该同时满足音乐时间关系、真实符号边界和视觉节奏层级。固定每行 5 小节，只限定换行数量；不必把 5 个小节强制等宽，更不能把每个音符按数量平分。** 当前项目的问题同时来自默认设置、符号几何和布局算法，继续单独降低间距百分比不能解决。

## 3. 商业软件公开说明透露了什么

### 3.1 JP-Word：先区分基础模型和较新改进

4.0 作者手册 [S2] 说明：音符参考点位于数字底部中央，相邻参考点的水平距离叫前进宽度；软件综合时值和水平定位参数决定该宽度。参数包括参考时值、参考宽度、线性因子和最小间隔。附属符号的边界矩形及其占位方向参与排版。手册还要求整拍处、小节线两侧留适当间隙，但没有公开完整公式或全部数值默认值。

较新的 6.95 官方更新 [S3] 有更直接的工程价值：

- A02：临时声部可反向调整主声部间距，改善拥挤重叠。
- A03：多声部可重排，合成总谱提供紧凑排版选项。
- A16、A17：对齐小节线、强制撑满的新算法专门控制小节线两侧空隙。
- A21：单声部、多声部、分谱合成总谱均可指定各行的小节数。
- A08：密集排版提供倚音、升降号缩小及间距压缩选项。

**重要修正**：不能只引用 4.0 手册说“临时声部永远不影响主声部间距”。4.0 旧功能确有这项限制和拥挤提醒 [S4]，但 6.95 官方已明确加入反向调整能力。比较应保留版本背景。

字体手册 [S5] 明确区分主字体与和弦、倚音、临时声部的字体变体，但没有给出统一扁体比例。

### 3.2 作曲大师：固定小节数、等宽小节、时值音距是不同选择

厂商的初始设置说明 [S6] 区分“小节等宽分配”和“随音符数量自动调整”，后者使内容多的小节更宽。另一篇说明 [S7] 单列“第一个音与小节线的距离”。更新说明 [S8] 还区分时值音距、两端小节线对齐音距和平分音距。

这能证明几种模式的存在，不能证明厂商使用某一种公开的弹簧公式。尤其不能把“行音符疏密 64”解释成 64 像素、64 毫米或每行 64 音。

### 3.3 MuseScore、LilyPond、Dorico、Sibelius 的可迁移部分

- MuseScore 官方 [S9] 把小节最小宽度、最小音符距离、时值间距比例、行尾拉伸阈值分开。其文档中的理想倍时值间距比默认是 1.5；1 是等距，2 是完全按时间比例。最终距离还受附件、避碰和两端对齐影响。这是五线谱软件的比较依据，不是简谱国标数值。
- MuseScore [S10] 会为歌词、和弦标记的水平碰撞扩大小节；部分上下附件更适合纵向避让。由此可迁移“分类处理占位”，不能把所有附件都转换成横向 padding。
- LilyPond [S11] 使用时值相关弹性距离，时值翻倍增加一个间距增量，并以常见最短时值作为参考，防止偶发极短音把全篇撑松。项目目前已经采用相近思想，问题不在“没有弹簧”，而在测量和最终分配是否一致。
- Dorico 的官方教程 [S12] 区分四分音符理想空间和短音最小空间，并提供局部水平调整；其示例单位是五线谱 space，不能直接当简谱数字宽度。
- Sibelius 官方 [S13] 将音符间距与多声部碰撞处理分开；同一时间的多个符号可能需要受控图形偏移。这类规则只可迁移约束思想，不能把五线谱符头错位规则直接套到不同简谱谱表。

## 5. 单声部小节：应分开测量的五个量

**锚点** `x_i`：音乐事件的横向时间位置，普通数字建议以 advance 中心为锚点。

**前进宽度** `a_i=x_(i+1)-x_i`：两个事件锚点间的距离，不等于数字间的白色缝隙。

**墨迹净空**：前符号右缘与后符号左缘之间的空白。数字 1、变音号、附点、歌词宽度不同，所以相同前进宽度可以形成不同净空。

**时值空间**：事件开始到下一个相关时间位置、乃至小节结束的空间。最后一个音符后面仍有时值空间，不能把所有剩余宽度都塞进前面的间隔而让它贴右线。

**边界净空**：小节线到首/末相关墨迹的距离。它不同于页面边距，也不同于末音的时间空间。

例如：四分音符后接两个八分音符时，不能因为数字都是一个字就等距；附点后到下一音的距离，也不是“附点本身占一个音符位”。音符时值决定理想空间，附点自身只额外形成右侧避碰约束。

建议对每个符号记录 `anchor`、`advance`、分部件墨迹边界和语义角色。不要只返回一个“含所有附件的总宽度”，否则难以知道一个小节为什么被撑宽。

## 6. 横向时值间距与伸缩

### 6.1 理想时间距离与防碰撞下限应分开

记事件间理想时值距离为 `s_i`，真实避碰下限为 `m_i`。布局应该优先接近 `s_i`，同时满足 `g_i >= m_i`。短音控制只调整理想值，不能将字形硬约束一起按百分比压缩。

建议比较三种候选：

1. 项目已有的对数模型：`s(d)=a+b*log2(d/d_ref)`，适当处理短于参考时值的情况。
2. 可配置倍时值比例：`s(d)=a*(d/d_ref)^alpha`，用来对照理想倍时值比 1.4、1.5、1.6 的视觉结果。
3. 完全时间比例，作为多声部对位诊断视图；不直接假定它就是默认出版模式。

不同声部出现的同一时刻必须共享 x；并不要求任意两个不同时值音符的最终印刷间距始终严格呈 2:1。国标要求长音空间更大，并要求按时间对位；版面中还要处理符号尺寸、拍群与上下声部限制。

### 6.2 一行拉伸时，不要均匀放大所有白边

自然小节宽度应包含必要墨迹、最小边界、理想时值间隔。行宽有剩余时，按可伸缩程度分配到时间空间；不要平均加到每个数字周围，更不要把小节边距与拍间空隙一起无上限拉大。

宽度不足时，顺序建议为：

1. 回收超出自然值的弹性空白。
2. 在保留节奏辨识的条件下收紧理想距离。
3. 在一行固定的 5 个小节之间重新分配宽度。
4. 若所有小节硬下限总和仍超过可用版心，报告“该字号/页宽下无法保持五小节且无碰撞”的明确状态。是否允许整体缩小字号，应是单独的排版策略，不能偷偷缩字或把音符重叠当成功。

尾行不满 5 小节时，保留自然尺度或有限拉伸，不应把两小节硬撑到五小节的全部宽度。[S2][S9]

## 7. 小节左右边距、拍号和行首缩进

应有独立的 `bar_start_clearance`、`bar_end_clearance`、`system_prefix_width`、页面边距。

| 情况 | 左边界的处理 | 右边界的处理 |
| --- | --- | --- |
| 普通音符开头 | 小节线到数字墨迹留最小净空 | 末音后的时间空间与最小墨迹净空共同决定位置 |
| 变音号开头 | 保证变音号最左缘不贴小节线；数字仍与其他声部对应拍位一致 | 同普通小节 |
| 倚音开头 | 左侧倚音簇整体预留；不把倚音当一个完整正拍 | 右端后倚音应在时值附件之后 |
| 反复起止 | 将粗线、细线、反复点算入边界符号实际宽度 | 不能用普通单线的相同锚点净空糊过去 |
| 中间变拍/变调 | 为调号/拍号建立前缀空间，相关谱表共享扩展 | 系统末提示性拍号要有独立尾部空间 |
| 行首 | 先分配声部名称、连谱号与拍号位置，再确定首拍列 | 系统右端对齐版心，不能用跨声部贯通线补齐 |

**边距应量到实际墨迹，不只量到数字中心。** 变音号、倚音可以让第一拍列整体右移，同时让无该附件的声部留出相应空白，符合 5.11.3.2 i)。

左、右边距不必数值相等：左端主要是清晰进入小节，右端还承担末音时值与终止边界。普通小节、反复小节、系统首末小节也不宜一律套同一个 gutter。[S3][S7][S9]

## 8. 减时线、增时线、延音线的不同布局责任

### 8.1 减时线首先表达拍群

- 从拍号与拍组构建结构树，再决定哪些事件属于同一连写组。
- 2/4、3/4 的常规短音按单位拍分组；连续八分音不应默认整小节连成一条。
- 3/8 不能机械套“每个八分单位断开”：国标 6.3.13.4 b) 允许连续八分减时线整小节连写。
- 6/8、9/8、12/8 需要复拍子的分组语义；5/8、7/8 需要明确 2+3、3+2、2+2+3 等拍组，不能只靠分母决定。
- 休止符和噪音符要参与国标的时值组合，不能遇到 `0` 就全断，也不能越过长休止随意连线。
- 第一层、第二层、第三层线的连续范围分别由细分关系决定；短附线方向应跟随节奏邻接关系，不能永远向右。

每个连写组先确定一个公共水平线高；不要让同组每个数字各自决定自己的线高。若有低音点，点在线组下方；不要为了容纳一个低音点把整条线拉下去，破坏数字与减时线的关系。

组两端要有受控外伸，但不必进入下个拍组或贴到小节线。缩紧时先保护组间可见断口。线厚、层间距、外伸长度应与字号/和弦样式统一计算，并同时用于测量和绘制。

### 8.2 增时线是拍位符号

`1 -` 中横线不是长音右侧随便补的一笔：它对应一个四分时值位置，必须与其他声部该时刻的数字/休止对齐。增时线本身的长度可以保持短，但它所占用的时间空间不应缩成一条横线的墨迹宽。

和音增时线有两个不同问题：是否共享，以及共享时放在哪个纵向高度。国标允许并列二/三声部的共享增时线放在和音上下居中处；这不改变和音最低层与普通音符基线的项目约定，也不意味着整个和音事件要在小节中水平居中。

### 8.3 延音线是跨事件连线

同音延音线与增时线不是同一种符号。其两端对准相关音符，跨小节/跨行保留承接；并列声部的各声线延音不能因为“节奏相同”而省成一条。连线高度与端点避让应参与纵向包络，不能把整条弧线的宽度当普通事件宽度加入相邻音符间距。

## 9. 和弦/并列声部的内部几何

先区分三个对象：单一等时值和音、独立节奏多声部、主旋律加小字从属声部。它们不能仅因为竖向叠在一起就套同一算法。

对当前选择的等时值和音样式，建议：

1. 所有层音共享一个横向时间锚点，按实际音高排序。
2. 保持最低音数字基线与同谱表普通数字基线一致；不按和音包围盒中心把它上下漂移。此项是当前用户已确认的版式选择，与 JP-Word 底部参考点体系相容；国标未在所核条文直接给出“统一最低音基线”的数值定义。
3. 数字扁体、层距、八度点与附件共同测量，层距按真实墨迹加必要净空，不能只有一个固定 `chord_gap`。
4. 同样是三音和弦，有两个八度点/临时变音号的情形可能更高、更宽；避免靠动态增大整行基线距离解决每个局部问题。
5. 变音号归属于具体层音，必要时使用紧凑列排列；不能把高层变音号挪到不明归属的位置。
6. 附点逐层画出并在同一列内对齐，复附点逐层保留，不允许三音只一个点。横向边界要从各层实际数字和附点算出。
7. 共享减时线在最低层之下；共享增时线按选择的并列略记样式放置。它们不应都沿用“事件最低音右侧”的一套固定高度。
8. 独立时值声部、仅部分音延长的和音需要各声线持续信息；不能先合成等时值 Event 再希望绘制层猜回来。

项目当前 90%×68% 是用户认可的候选字形配置，可继续作为比较基线；其本身不能证明附件数量、线条高度与时值对位已经符合标准。

## 10. 多声部小节：共享时间列，独立碰撞约束

推荐先建立共同时间节点：所有谱表的可见音符、休止符、增时线拍位、拍群边界、必要的歌词时间与连音细分。时间使用 `Fraction`；不要先量化为像素，也不要为每个最小公倍数刻度都建一列。

对每个谱表/声线分别记录同一时间列的真实部件，形成约束：

```text
x(t_j) - x(t_i) >= 该声线从 i 到 j 的最低避碰距离
所有声线的这些不等式共同成立
同一音乐时刻只有一个共享 x(t)
```

需要特别注意：**不同谱表的左右包络直接取并集，再对相邻时间列做避碰，可能过度撑宽。** 上面谱表的附点和下面谱表的变音号并不一定在相同纵向高度，不能凭它们的横向投影就认定碰撞。应按同一声线/相关歌词带、实际有纵向重叠的部件建立约束。

某声部跨过多个共同节点才出现下一个音符时，应对这两个实际事件的端点建立跨度约束。不要把一个长跨度的所有空间机械平均分配给每个联合小区间，这会让不同声部交替密集时重复放大宽度。

求解顺序建议：

1. 对各声线分别建立硬约束。
2. 合并共同时间节点，求得满足所有约束的最小宽度。
3. 加入时值相关的理想距离与拍群偏好。
4. 在本小节得到的可用宽度中求共同 x。
5. 所有声部复用这张时间位置表，绘制时仅改变纵坐标。

**声部交换顺序不应改变横向时间位置。** 第一声部休止、第二声部密集，以及相反顺序，应求出相同的 x(t)。只有明确指定的视觉主从权重可以影响软约束，不能依赖数组第一个元素。

## 11. 固定每行 5 小节的宽度分配

当前代码的固定模式实际上是等宽网格，过密小节可占多列，这又会让一行实际不足 5 小节。它不是严格意义上的“固定每行 5 个小节”。

推荐把以下概念在模型里分开：

- **小节数量固定**：正常完整行有 5 个小节。
- **小节宽度等分**：5 个小节宽度一样，是额外样式，不是数量固定的必然后果。
- **跨系统列线对齐**：上下系统的小节线落在同一组列，是另一项版式偏好。

对于当前《结婚记》的出版目标，优先选择：**固定数量 5；同一系统所有声部共享相同的小节边界；每个小节按内容获得不同宽度；不同系统不强制相同列宽。** 这能把全休止/少音小节的多余空间让给密集旋律，同时保留每行 5 小节的阅读习惯。

若用户另外要求严格等宽网格，就保持等宽，但应清晰面对密集小节的可行性限制，不能把“占两列”悄悄当作仍完成了每行 5 小节。

宽度分配可以写成：

```text
sum(W_1 ... W_5) = 系统可用宽度
W_j >= M_j（第 j 小节联合求解的硬下限）
W_j 尽量接近 N_j（第 j 小节自然宽度）
额外空白按可伸缩的时间间隔分配
```

每小节符号总数不能只取最多的那个声部：第一声部前半拍密集、第二声部后半拍密集，联合约束可能比任何一条单独声部都宽。反过来也不能把所有声部的音符数相加，重合时间不应重复占列。

## 12. 休止符、歌词、连音与装饰音

| 元素 | 应如何参与小节布局 | 常见错误 |
| --- | --- | --- |
| 普通休止符 | 与音符一样占时值位置；附点与减时线参加避碰/分组 | 把 `0` 当可随意居中的空白符号 |
| 多小节休止略记 | 使用自己的居中与计数规则 | 与普通整小节休止、全音符混成一个“居中单元” |
| 中文歌词 | 核心唱词对准音符，前缀/标点独立处理 | 标点也算入居中核心，令数字与汉字视觉错位 |
| 外文歌词 | 按音节真实宽度及连字符/延长线占位 | 所有词都按一个汉字宽度计量 |
| 多段歌词 | 各行分别形成碰撞带，取实际最紧约束 | 把不同高度两段歌词的左右极值合成一个过宽盒子 |
| 三连音等 | 时间精确；相同组内尽量稳定节奏间距；数字/括弧另外避让 | 因其中一音有变音号就使整组三个间距忽大忽小 |
| 不同连音对位 | 按有理数音乐时间共用坐标 | 用“第三个音对第三个音”来对齐 |
| 倚音 | 作为受控的非主时值簇附着于本音 | 把每个倚音占成一个完整八分音符空间 |
| 力度、演奏记号 | 先按归属锚点定位；短文本避碰，长文字用专用带处理 | 一个很长的说明词把所有音符间距都等量撑开 |
| 跨小节渐强、跳房子、连线 | 以端点/跨越关系约束，绘制后检查 | 用跨度总宽作为单个音符宽度，导致重复计算 |

歌词较宽时，允许局部时值间距受到影响，但仍应维护拍位与声部对位，不应把乐谱退化为“按文字逐字等距”。[S2][S4][S10]

## 14. 可试验的项目参数，不能冒充厂商默认值

建议定义 `u` 为当前普通数字 `0` 的 advance 宽度，`h` 为普通数字的真实墨迹高度。**不是字号 em，也不是字形的最窄笔画宽度。** 下列仅是下一轮 A/B 打样起点，须和同曲谱例一起评估。

| 参数 | 建议起点 | 说明 |
| --- | --- | --- |
| 相邻普通数字硬净空 | 0.25～0.40u | 不含字形本身宽度，字号变化同步更新 |
| 普通小节首端墨迹净空 | 0.70～1.00u | 先避免额外 gutter 与线外伸重复叠加，再比较更宽版 |
| 小节尾端最小墨迹净空 | 0.55～0.90u | 不含末音持续时间所占空间，不能以此强行把最后一音贴线 |
| 同拍短音理想间距 | 以实测自然距离为基线，A/B 约 ±10% | 短音没有一个跨字号、跨谱例通用的绝对间距 |
| 拍间额外空隙 | 同拍间隔的 0～20% 作为软偏好 | 不是固定硬加 13 单位；均匀分拍多声部优先保持对位，拍群还由断线表明 |
| 倍时值理想间距比 | 对照 1.4、1.5、1.6 | 用于比较候选曲线，不要求最终距离严格保持该比 |
| 和音数字缩放 | 当前 0.90×0.68 | 用户确认的基线，非国标强制比例 |
| 和音层间净空 | 0.12～0.22h 起步，附件避让优先 | 这是墨迹间净空，不是数字基线距离 |
| 减时线组端外伸 | 0.10～0.20u，按墨迹边缘量 | 组内数字宽度不同，不能简单以所有锚点 ±固定 12 画线 |
| 多层减时线间距 | 0.20～0.28h 起步 | 同时核对线厚、低音点、最终打印尺寸 |
| 数字到第一条减时线净空 | 0.12～0.20h 起步 | 注意是墨迹下缘到线条上缘 |
| 线厚 | 普通字形主要细笔画的约 0.8～1.0 倍作为打样起点 | 看 100% 实际纸面与 300 DPI 输出，不能只看高倍浏览器放大 |

为避免误用，此表参数不能整批直接替换现有默认值：应先统一几何测量，再测试一项改变对一个小节、一个系统、整页的影响。页面左右 10 mm 等是现有产品默认，不是从这些商业样张反推出的出版标准。

## 15. 下一轮实施顺序与验收

**第一批：修正确认的记谱/布局错误。** 整小节首拍位置、和音逐层附点、常规拍群、窄小节降级覆盖、声部顺序依赖。先有明确的正确性，再比较美观。

**第二批：统一小节布局核心。** 单声部和多声部共用时间列与硬约束；测量、固有宽度、最终分配和实际绘制使用同一份几何结果。自动/固定模式只提供不同断行与目标宽度。

**第三批：固定 5 小节的系统宽度优化。** 内容自适应分配宽度、自然首尾空间、有限拉伸。保留最后一行与特殊小节的明确规则。

**第四批：线条与和音附件的视觉打样。** 在当前扁体基础上评估逐层附点、共享增时线高度、低音点与减时线关系、连音与延音曲线。用同曲、同音符字号、同页面宽度比较，不用不同曲目的页数判断优劣。

至少应建立以下用例矩阵：

| 类别 | 用例 | 必须验证 |
| --- | --- | --- |
| 常规节奏 | 2/4、3/4、4/4 的均匀八分/十六分 | 拍群清楚，同拍等结构间距稳定 |
| 特殊分组 | 3/8、6/8、9/8、5/8 的两种拍组、7/8 | 分组遵循拍型，而非分母计数 |
| 长音 | 整小节单音/和音，带增时线，多谱表长短音并列 | 首拍位置、横线拍位、尾部时间空间 |
| 和音 | 二～五层、各层不同八度点/变音号、附点和复附点 | 基线、附件数量、归属和几何无冲突 |
| 休止 | 普通休止、附点休止、连续普通休止、多小节略记 | 居中例外分明，组合与时值一致 |
| 联合密集 | 上声部前半密、下声部后半密；稀旋律配密伴奏 | 所有声部共同满足约束，不能只让主声部好看 |
| 顺序不变性 | 交换声部、改变同刻事件插入顺序 | 同一时间列 x 不变 |
| 字号/页宽 | 80%、100%、120%；3/4/5 小节 | 不因字形与固定 padding 不同步产生越界 |
| 边界附件 | 首音变音号/倚音；反复号；变拍；提示拍号 | 左右实际墨迹净空正确 |
| 歌词 | 中文标点、多字一音、英文长词、多段歌词 | 核心唱词对位，真实冲突才扩宽 |
| 连音/跨越 | 三对二、五对三、跨小节延音、跨行圆滑线 | 时间准确，端点及逐声部线条完整 |
| 固定数量 | 同行四个稀小节加一个密小节 | 正常仍 5 小节，宽度按需分配；不可行时明确报告 |

几何验收分别统计：时间列误差、实际墨迹碰撞、边界越界、拍群断口、附件缺失。共享减时线与所属音符总包络的相交，不能和两个数字真正相撞混为一个计数。

视觉验收至少看：单个和音、一个小节、一个完整系统、整页；原始矢量与高分辨率导出都检查。不要再以“所有测试通过”“压到几页”作为商业出版级的替代判据。
