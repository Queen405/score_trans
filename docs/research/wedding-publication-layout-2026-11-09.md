# 《结婚记》多声部固定小节版式实测（2026-11-09）

本轮使用用户提供的完整文本，固定为 `tests/fixtures/publication/wedding-three-part.jianpu`。输入为 8 个源页面、3 个谱表，每个谱表 187 小节；保留音符、时值、和弦、力度及连线数据。

## 验收条件与实测结果

复现截图的实际设置：每行 5 小节，整体比例 88%，数字字号 100%，声部间距 0%，系统间距 20%，按拍断开减时线。优化前后使用相同的这些设置。

| 项目 | 优化前 | 本轮最终输出 |
| --- | --- | --- |
| A4 输出页数 | 18 | 9 |
| 全部系统数 | 38 | 38 |
| 第 120 小节所在页面 | 第 12 页 | 第 6 页 |
| 该页覆盖范围 | 第 120–129 小节 | 第 120–139 小节 |
| 该页系统数 | 2 | 4 |
| 数字字号与整体比例 | 100% / 88% | 100% / 88% |
| 和弦最低音对齐 | 保留 | 保留 |

新默认声部间距为 75% 的独立基线样例输出 11 页；该结果与用户截图的 0% 设置分开记录。固定列网格与已有密集小节占多列的保护规则保持兼容。

## 找到并修复的原因

- 原先绘制按相邻系统高度安排位置，分页仍按全篇最大行距预留空间，产生大量可见留白。现在分页、页面高度估算与绘制共享同一个相邻系统距离模型。
- 谱表高度同时包含上方音符扩展和下方预留；接入下一个谱表时再次预留其上边界。高和弦导致两次计入留白。固定多谱表布局改用实际数字、八度点、减时线、力度、歌词、连线、跳房子与小节线的上下包络。
- 下方谱表不显示小节号，却预留了对应空带。现在只有实际显示小节号的谱表预留该位置。
- 钢琴大括号顶部固定在一个常量位置，未覆盖高和弦。现在依据两行谱表的实际小节线范围绘制，并增加系统首端连谱线。
- 首次声部名称采用缩放适配左边可用空间，保留完整名称并避免越界。

## 纵向伸缩模型

先按自然间距排页；当增加下一系统只需少量空间时，仅压缩留白。以数字字号为相对单位，钢琴组内净空从 0.45 倍最多收紧到 0.30 倍；乐器组间从 0.85 倍最多收紧到 0.65 倍；系统边界的额外留白从 1.00 倍最多收紧到 0.88 倍。已有间距百分比设置继续参与计算。

压缩比例在一页内一致，用有限二分计算满足当前页面的最小压缩量。低音点、和弦、歌词、力度和连线的占位不参与压缩。本次复现设置下，压缩后仍保留“组内 < 组间 < 系统间”的留白层级。剩余页高仅在有限上限内补入系统间隙。显式分页优先，尾页孤立系统在不增加页数的前提下重新平衡。

该模型沿用前序调研中 LilyPond 分组间距、最小留白与可伸缩间距，以及 MuseScore 的大谱表间距和最大页面填充距离的设计原则。国标依据为 GB/T 46845-2025 第 5.2.4、5.3、5.4、5.11 条；上述间距倍率是项目的排版参数，并非国标给出的强制数值。

## 实图检查与回归

- 保存优化前整套 SVG/PNG；四轮改版均生成真实图片检查。
- 最终生成 9 页 SVG、9 页导出 PNG、9 张 Chromium 浏览器截图及 HTML 预览目录，检查全谱总览、密集和弦页、第 120–139 小节和最后一页。
- 3/4/5 小节设置分别验证：分页完整、页脚不越界、组内与组间净空保留、重复分页结果不漂移。
- 整谱验证 1–187 小节号连续，同一播放时刻的各谱表横坐标一致，不同谱表的事件包络无交叠；无页面越界、小节越界或事件重叠诊断。
- 原几何检查中仍会记录共享减时线包围盒与所属事件包围盒之间的 `geometry-overlap`；这类诊断未作为跨谱表事件碰撞计数，也未从报告中隐藏。
- 引擎版本升级为 `publication-30`，使历史恢复能够识别旧版输出并要求重新渲染。旧 SVG 文件保留原有内容。

## 复现与查看

使用 Bash 及项目 venv：

```bash
export PYTHONPATH=backend
.venv/Scripts/python.exe tools/review_publication_score.py \
  tests/fixtures/publication/wedding-three-part.jianpu \
  work/wedding-review/final-publication-30 \
  --title 结婚记 --measures-per-system 5 \
  --part-gap-percent 0 --system-gap-percent 20 --break-beams-at-beat
```

实际运行还需项目要求的后端鉴权环境配置。输出 `index.html` 提供逐页 SVG/PNG，`contact.png` 为总览，`metrics.json` 保留几何诊断。浏览器截图与用户原图对比保存在本轮本地审查目录中。
